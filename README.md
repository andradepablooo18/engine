# So why did I started this project?
This is a school project, specifically, a project for my Analysis and Approaches subject in the International Baccalaureate Diploma Program.
At this point, my engine (which still doesn't have a name) is capable of:
1. Handling user input
2. Managing window creation and the application loop.
3. Creating 3D objects and rasterizing them using either solid colors or textured materials with UV coordinates.
5. Providing several math modules used throughout the rendering pipeline (Matrix4, Vector2, Vector3, Vector4, and others).
   
As you can see, the engine is still very simple. There are many features I'd like to add, but those are projects for another day—assuming I decide to come back and continue working on it.

# What's still missing?
Not only features, but also improvements to the overall codebase:
1. Vertex normals.
2. An OBJ model loader.
3. Additional rendering modes (wireframe and point rendering).
4. Orthographic projection.
5. A complete scene system (currently only the Scene structure exists).
6. A logging system for errors and warnings.
7. A more consistent naming convention for files, variables, and functions.
   
I know this is far from being a production-ready engine. There are still many things to improve, optimize, and redesign. However, considering that this is the largest project I've built completely on my own and without following a tutorial, I'm genuinely happy with how much I learned throughout the process.
If you happen to find questionable design decisions or even obvious mistakes in the code... that's part of the journey. I hope you'll also find the progress, experimentation, and lessons learned along the way, because every line of code in every file reflects my evolution towards a better programmer :).
